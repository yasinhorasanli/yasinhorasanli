#### Featured: XCRS

Pick the skills you enjoy, dislike or are curious about; XCRS suggests IT career roles that fit, the gaps to close, and free learning resources, with a plain-language explanation for each. → **[xcrs.app](https://xcrs.app)** · [repo](https://github.com/yasinhorasanli/XCRS)

- A scoring engine over a curated catalog of 259 skills and 30 roles (checked against O\*NET and ESCO) decides; a self-hosted LLM only explains, grounded in the facts the engine used
- Ollama (Qwen 3.5) with LangChain; PostgreSQL + pgvector for skill matching
- Self-hosted production plus an AWS environment provisioned with Terraform
